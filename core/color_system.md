# 六色学术语义

本表为引擎色值权威源。HEX 为 sRGB；PDF RGB 按每个通道整数除以 255 得出，不使用另一组近似色值。语义适用于笔记标签与未来 PDF 内嵌“下划线 + 附带评论”；颜色不能替代文字说明或证据。

| 标准名 | 兼容别名 | HEX | RGB（0–255） | 学术语义 |
| --- | --- | --- | --- | --- |
| amber | yellow | `#E5A00D` | 229, 160, 13 | 背景与研究动机 |
| red | crimson | `#D83B01` | 216, 59, 1 | 核心矛盾、痛点与物理硬伤 |
| green | — | `#107C41` | 16, 124, 65 | 核心机制、创新贡献与主实验结果 |
| blue | — | `#0078D4` | 0, 120, 212 | 硬件拓扑、通信与时延预算 |
| purple | violet | `#5C2D91` | 92, 45, 145 | 核心公式、控制律与损失函数 |
| orange | — | `#D9531E` | 217, 83, 30 | 核心假设、客观局限与工程避坑 |

## 从旧工作流迁移

旧技能文档已经列出上述 HEX，但旧批注脚本实际使用下面的浮点 RGB，两者并不等价：

| 标准名 | 旧脚本 RGB |
| --- | --- |
| amber | (0.90, 0.60, 0.00) |
| red | (0.85, 0.15, 0.15) |
| green | (0.10, 0.65, 0.25) |
| blue | (0.00, 0.45, 0.85) |
| purple | (0.50, 0.20, 0.75) |
| orange | (0.90, 0.35, 0.05) |

选择文档 HEX 是为了让文档、未来实现和跨客户端显示有唯一且可精确复算的定义，保留既有六色语义与别名。此举不是对旧批注自动改色；现有 PDF 保持原状，未来写回只更新引擎明确拥有的批注。未识别色名应报错，避免静默映射为 amber。首版仅发布色表，不实施 PDF 修改。

一图流另用深绿 `#126344`、浅绿 `#F0F6F2` 和棕色 `#884827` 表达版式层次；它们是展示配色，不是六色批注映射。
