# 中文论文一图流任务

在用户请求一图流／graphical abstract／论文单页速览，或精读同时满足高价值闭环条件（`usefulness: 高`、`status: done` 且具备清晰方法／系统因果链）时执行；未闭环或无清晰方法因果链的普通精读不自动触发。读取 `paper-flow show spec` 与 `paper-flow show one-pager-template`，复用已核查的笔记、原文证据及库内图片；若目标 Vault 配有本地视觉参考，按需对照其版式语言。展示页不是证据来源，不继承示例模板或视觉参考的假设与数值。

## 内容先行

在输出目录写 `one-pager-content.md`：

1. 文献信息：作者、年份、原题、期刊/会议、可核实 DOI；来源笔记相对路径、读取范围与当前缺口。中文主标题用技术抓手说明贡献。
2. 方法链：每节点写标题、输入→输出、机制/参数、关键公式、公式前直觉、符号定义、图/式/页码及已核查状态。保留原 LaTeX 供复核，排版时改为 Typst 数学。
3. 反馈：测量量回到哪个模块、执行器如何改变对象。区分观测、辨识、控制、训练与部署；开环/离线工作画数据流或验证链，不虚构闭环。
4. 验证证据：指标、值、单位、设置、样本数/分母（原文给出时）、基线、出处，明确拟合还是独立测试。
5. 成立边界：原文假设与失效条件；阅读者推导标 **【笔记推断】**。
6. 研究启发：**【笔记推断】** 可复用机制及可执行验证动作；课题未知写“潜在关联，待确认”。
7. 图源：相对文件名、图号、裁剪范围、原文位置；裁剪保留坐标轴、图例和尺度。

每项状态为已核查、待核查或不适用（附理由）；未看到不等于论文未报告。关键证据缺失时图上标“阅读草稿／关键证据待核查”。

## 版式与制作

将 `paper-flow show one-pager-template` 的输出保存为本篇 `one-pager.typ` 后替换示例，保留可编辑正文、公式与箭头。模板无网络包或外部图依赖，需要本机 Typst 和中文字体（优先 Noto Sans SC 或 Microsoft YaHei）；先检查字体。真实图片按相对路径复制进同目录，不使用缓存绝对路径；原图保纵横比。不用 AI 装置/结果图冒充论文证据。

16:9、960pt×540pt 白底：约44pt边距，黑色主标题26pt、灰色原题14pt；中间默认四节点方法链（可按实际改三节点），首格真实硬件或架构图，后续浅绿卡片与深绿标题；底部三栏“验证证据／成立边界／对本课题的启发”，最底小字号出处。**正文中文字数建议控制在 350–420 字**，优先可读性与留白，正文字号保持 `12.5pt–13pt` 以上，避免卡片底端拥挤和单字孤行折行。无阴影、无强制 Logo，无来源素材时不添加组织标识。

**Typst 特殊字符硬性禁忌**：Typst 中 `~` 是**不换行空格**（会导致数值范围丢字符），表示数值区间时一律使用 en-dash `–`（如 `+13.9–24.8 pp`）或全角 `～`；注意转义 `#`、`$`、`*`、`_`、`@`、`<`、`>`。

方法节点服从论文：控制可用“感知→辨识→外环→内环”，RL可用“任务与观测→表征/训练→策略与目标→执行反馈”，传感器可用“结构→换能→标定→输出应用”。不为四格补造模块。模板默认无反馈线，仅在原文真有闭环且反馈对象明确时添加，并同步调整箭头位置。

每个核心公式前给直觉，保留必要变量说明；过长时选核心项并定位完整式到笔记，避免无限缩字。脚注保留作者年份、DOI（已核实才写）、关键图式号；完整台账留在内容文件。

从输出目录执行：

```text
typst compile one-pager.typ one-pager.svg
typst compile one-pager.typ one-pager.png --ppi 144
```

PNG 为1920×1080。PDF仅按需导出。编译器缺失时交付源码及结构化内容，明确没有成图。PPTX、HTML或其他格式按用户选择；整页 PNG 包装的 PPTX 不称为原生可编辑。

## 归档、复核与交付

默认放在来源笔记同级 `assets/<paper-slug>/`，含 `.typ`、`.svg`、`.png`、`one-pager-content.md` 及引用原图。当随精读条件自动触发或用户要求融入笔记时，在 Citation、核心启发看板和阅读范围之后插入或更新如下“文献一图流速览” Callout 块（使用笔记相对图片路径）；仅在用户明确“只导出图片”时不修改笔记：

```markdown
> [!NOTE] 文献一图流速览
> ![文献方法、证据与边界](assets/<paper-slug>/one-pager.svg)
> [PNG分享版](assets/<paper-slug>/one-pager.png)
```

编译后**必须实际打开查看 `one-pager.png` 视觉图片**：确认只有一页、16:9、无裁切/溢出/遮挡/破图/缺字/丢失区间连接符、无尴尬单字折行、公式上下标完整、960×540仍能辨识核心结论、箭头与原文因果一致；SVG图像嵌入或路径可解析、文字可迁移。溢出先删重复语句、缩短标题、调整图文比例，再调字号。

复核“更新频率≠带宽”“拟合误差≠独立泛化”，保留单位、分母、工况及出处。交付 PNG 预览、SVG、可编辑源文件与影响结论的缺口。一图流不改变笔记 `status`；不因制图重复维护索引，不自动发布外部服务或重写历史结构。
