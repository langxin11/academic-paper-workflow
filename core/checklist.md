# 精读交付验收

与 `paper-flow show spec`（v3.2）配套使用；核验原文，不以笔记自己的“已核查”声明作证。

- [ ] 标题可检索，首屏用零黑话语言讲清研究矛盾、核心机制、量化表现与边界；中文为主，必要英文术语保留。
- [ ] 新笔记按正式模板「首屏看板 + 五段渐进主干」组织（§1 问题与切入 → §2 方法走查 → §3 证据与审视 → §4 边界与破局 → §5 迁移与行动）；旧笔记保留原有组织。
- [ ] Frontmatter YAML 合法且含冒号字段已加双引号；无冗余 `topic`/`keywords`；`project` 落入 6 个标准桶；`tags` 从 18 个受控词表选取且不超过 3 个。
- [ ] Citation、DOI（可核实才写）与实际材料来源可追溯；`zotero_link` / `pdf_link` 不混填父子 key 且无截断前缀。
- [ ] `status` 与实际情况一致；首屏有紧凑的 30 秒决策看板（`本质创新` <100 字，含定性裁定与阅读路线）及默认折叠的阅读范围与状态依据。
- [ ] §1 用物理场景描述输入输出（不跨级抛 §2 符号），按需提供 `读前 1 分钟概念桥`，并讲顺底层死锁与前人对比；§2.1 含单样本具象走查，各子模块按「不做会怎样 → 直觉与机制 → 公式 → 实证钩子」展开。
- [ ] §3 每组实验先给「一句话看懂本组实验」，保留设置、Baseline、指标、实测值、单位及必要分母，并在同节当场审视对比公平性、统计口径暗门与外推边界。
- [ ] 后台工具日志与无害勘误已静默消化：正文不含 MinerU/OCR 修复汇报、任务号或 SHA-256 哈希；仅数学硬伤、前后矛盾或误导口径才显式预警。
- [ ] 系统/框架/数据集论文的损失、指标、控制律或标定目标已核查；已区分拟合/独立测试、频率/带宽、测量/估计/真值、训练/部署信息。
- [ ] 作者原意与 **【笔记推断】** 清楚区分；§4 每条创新点绑定具体短板及可验证新机制，§5 关联已知课题与可执行 Action Items。
- [ ] 图片真实存在于笔记相对 `assets/<paper-slug>/`（路径无空格）；无本机绝对路径、断链、幻觉空双链、未填占位符或不配对公式，折叠 Callout 每行以 `>` 开头。
- [ ] 关键证据缺口保留 `in-progress`；`done` 对应明确范围内的证据闭环。
- [ ] 人工索引已登记有效双链和导读，或固定“待补收录”有待办；`paper-flow index --check` 干净通过。
- [ ] 只修改任务相关资料，保留旧入口、历史笔记结构、人工批注、绘图内部数据及项目设置。

若另交付或条件触发一图流：确认满足触发条件（显式要求，或 `usefulness: 高`、`status: done` 且具清晰方法/系统因果链）；Typst 中禁止用 `~` 表示数值区间（改用 `–` 或 `～`）；控制约 350–420 中文字；实际编译并**打开 PNG 视觉核查**单页 16:9、无溢出遮挡缺字、无单字孤行、960×540 可读；自动触发或要求融入笔记时，“文献一图流速览” Callout 位于首屏之后且相对路径可解析。若渲染失败，交付明确为源码草稿。

若执行 PDF 写回：整批引文预检、页码基准、完整匹配和歧义检查通过；稳定 ID 去重，只更新引擎批注；保留手工批注；当轮备份、临时文件重开验证、源文件变化检查和原子替换均成功。分别记下预检结果、备份路径和实际写入数。
